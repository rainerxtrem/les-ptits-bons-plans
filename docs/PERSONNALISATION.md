# Personnalisation depuis l'éditeur de thème

Ouvrez **Boutique en ligne > Thèmes > Personnaliser**. Tout se règle sans toucher au code.

## Réglages du thème (icône engrenage)

| Groupe | Réglages |
| --- | --- |
| Logo et favicon | Logo (image), logo clair pour le pied de page sombre, largeur ordinateur et mobile, favicon |
| Couleurs | Direction « Marché malin » : vert de marque, vert foncé, vert clair, jaune bons plans (boutons, étiquettes), rouge promo (prix réduits, pastilles), neutres |
| Typographie | Inter (hébergée dans le thème), titres très gras ; possibilité de la remplacer par la bibliothèque Shopify, échelle des titres et du texte |
| Mise en page | Largeur maximale, arrondis des cartes et des boutons, apparition discrète des sections |
| Cartes produit | Format d'image, cadrage, image au survol, marque, ajout rapide, style du badge promo (pourcentage calculé ou « Bon plan ») |
| Panier | Tiroir latéral ou page, note de commande, champ code de réduction, collection suggérée quand le panier est vide |
| Recherche | Suggestions instantanées, prix dans les suggestions |
| Coordonnées | E-mail, téléphone, adresse, horaires (affichés dans le pied de page, le menu mobile et la page contact ; un champ vide n'est pas affiché) |
| Réseaux sociaux | Instagram, Facebook, TikTok, Pinterest, YouTube, LinkedIn |
| Partage | Image par défaut pour les réseaux sociaux |

> Contrastes vérifiés : texte noir sur jaune 12,05:1, blanc sur vert 5,34:1, blanc sur rouge 4,99:1. Évitez le texte vert sur fond jaune (3,7:1).

## Sections disponibles

Chaque section propose un **choix de couleurs** (blanc, gris clair, vert clair, vert, vert foncé, jaune, rouge promo) et des **marges** réglables, pour alterner les fonds et rythmer la page.

| Section | Usage |
| --- | --- |
| Bannière d'accueil | Image ordinateur et mobile, disposition côte à côte ou texte sur l'image, hauteur, alignement, assombrissement, surtitre, titre (les mots en *italique* sont surlignés en jaune), pastille ronde « Prix mini », texte, deux boutons |
| Grille de catégories | Blocs « Catégorie » : collection, image, titre, accroche, lien. 2 à 5 colonnes, titre sous l'image ou sur l'image |
| Produits mis en avant | Collection, nombre de produits, grille ou carrousel. Filtre « tous / disponibles / en promotion ». Masquage automatique si vide. Préréglages « Promotions » et « Nouveautés » |
| Image et texte | Bannière éditoriale asymétrique, image secondaire superposée, filet doré, deux boutons |
| Engagements | Bande de réassurance (icône, titre, texte). N'indiquez que des engagements réels |
| Sélection saisonnière | Tuiles (image ou fond de couleur, étiquette, titre, lien) pour Noël, la rentrée, les idées cadeaux… |
| Newsletter | Inscription native Shopify, mention de consentement, lien vers la politique de confidentialité |
| Texte enrichi | Surtitre, titre, texte, bouton |
| Étapes / colonnes | Étapes numérotées (page Cadeaux d'entreprise) ou colonnes de contenu |
| Galerie d'images | Exemples visuels avec légendes |
| FAQ | Thèmes et questions-réponses (accordéons) ; génère les données structurées FAQ |
| Formulaire de contact | Mode « Contact » (sujets configurables) ou « Demande professionnelle » (entreprise, nombre de destinataires, budget, date) |
| Produits complémentaires | Recommandations Shopify (similaires ou complémentaires) ou collection choisie |

## Fiche produit

La section **Fiche produit** contient des blocs réorganisables : marque, titre, prix, disponibilité, référence, sélecteur de variantes (boutons ou liste), boutons d'achat (quantité, paiement express), informations de livraison, description, accordéons, partage, Liquid personnalisé et blocs d'applications.

**Métachamps** : dans un bloc « Accordéon », cliquez sur l'icône de source dynamique du champ *Contenu* pour le relier à un métachamp produit (par exemple `Caractéristiques` ou `Conseils d'utilisation`, à créer dans **Paramètres > Données personnalisées > Produits**, type « Texte enrichi »). Un accordéon vide est automatiquement masqué.

Réglages de la section : galerie (image principale et vignettes, ou grille), format des médias, cadrage, zoom, fil d'Ariane, barre d'achat fixe sur mobile.

## Collections

La section **Collection : produits** gère l'en-tête (surtitre, description, image, nombre de produits), le nombre de produits par page, les colonnes, les filtres (colonne latérale ou panneau) et le tri.

## En-tête et pied de page

- **Barre d'annonce** : jusqu'à 5 messages, avec lien, défilement manuel ou automatique (avec bouton pause).
- **En-tête** : menu principal et menu mobile, logo à gauche ou centré, en-tête fixe (non, toujours, ou en remontant), recherche. Blocs **Visuel de méga-menu** : image et titre associés à une entrée du menu (par exemple « Catalogue »).
- **Pied de page** : présentation, coordonnées, réseaux sociaux, jusqu'à 4 colonnes (menus, texte, newsletter), sélecteurs pays et langue (si plusieurs marchés), moyens de paiement réellement activés, liens légaux automatiques.
